# Brag Plan: ResumeCraft

## What is this app?
ResumeCraft is an AI-powered ATS resume builder combining Google Gemini and the RenderCV Typst typesetting engine to turn weak resumes into 100% ATS-compliant, vector-sharp career weapons formatted with the proven XYZ formula.

## The angle
A ridiculous, high-stakes Silicon Valley startup launch. Treating applicant tracking systems like dystopian gatekeeper bots from a sci-fi thriller, and ResumeCraft as the open-source typographic rebellion that destroys them.

## Hook (first 2-3 seconds)
Stark dark screen with neon red warning:
"IN 2026, 94% OF RESUMES ARE VAPORIZED BY A 15-YEAR-OLD ATS REGEX SCRIPT."
"We couldn't fix corporate hiring. So we built a weapon against it."

## Key moments (the middle)
- **Moment 1 (XYZ AI Rewrite)**: Live transformation of a mediocre bullet point ("Wrote Python APIs") into a bulletproof accomplishment statement using Google Gemini: "Accomplished 42% latency reduction across 12M daily queries by deploying distributed vector indexing."
- **Moment 2 (1-Page Auto-Fit Engine)**: The tragic "2-page spill" (3 lines on page 2) instantly collapses into a perfect single-page layout using 4 reflow compression tiers without touching font legibility.
- **Moment 3 (ATS Algorithm Defeat)**: An automated ATS scan simulation running in real time—score climbs from 34% (Failing) to 98% (Dominant Green).

## Outro / punchline
"Recruiter bot: DEFEATED."
"Stop pleading with algorithms. Build the resume they can't filter out."
ResumeCraft wordmark + live URL.

## User flow worth showing
1. Paste weak resume bullet point -> 2. ResumeCraft XYZ AI re-engineers impact metrics -> 3. 1-Page Fit reflows typography -> 4. Direct vector ATS PDF export.
